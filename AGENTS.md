- Site language uses src/lib/i18n.tsx with inline t(en, bn) pairs; SSR renders English and the saved choice applies after hydration (why: no hydration mismatch, no extra dependency).
- Orb phase is integrated continuously by orb-motion.ts; real assistant states change target velocity, never reset phase (why: smooth transitions without restarting orbits).
- Shared motion/react entrances key on pathname only; Block Drift and orb rendering pause offscreen, in hidden tabs, and under reduced motion (why: consistent page entrances without query remounts or unnecessary GPU work).
- Luxe Glass surface roles are defined in src/styles.css; selected midnight sections scope the same semantic roles, and shared controls use those roles (why: full-product consistency without altering feature behavior).
- Customer mobile workspace navigation uses the shared Sheet primitive rather than a custom overlay (why: focus management and keyboard dismissal stay consistent with dialogs).
- Public hero 3D ambience lives in src/components/hero-3d.tsx (lazy React Three Fiber canvas, first child of a relative hero with content siblings marked relative); /solutions redirects to /automations where SolutionsSection renders (why: one ambient scene shared by all public pages, no SSR/hydration risk, old links keep working).
- Shared popups and navigation use the Material 3 CSS easing tokens; page transitions must not transform their wrapper (why: detached fixed navigation and dialogs must remain viewport-positioned).
- Solution destinations share storefront availability rules with pricing; admin reads fail closed and public reads use a narrowly granted anonymous setting (why: deleted cards stay deleted, hidden products stay hidden, and failed reads cannot overwrite saved edits).
